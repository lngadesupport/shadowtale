# ShadowTale — Hytale 0.6.8 Visual Codec Contract

This document records only facts verified against the official Release 0.6.8 Asset Reference.

## Environment

Official asset path:

    Server/Environments/*.json

The 0.6.8 page documents `Parent`, `Tags`, `WaterTint`, `FluidParticles`, `SpawnDensity`, `BlockModificationAllowed`, `WeatherForecasts` and `WeatherForecastSeed`.

## Weather

Official asset path:

    Server/Weathers/*.json

The 0.6.8 page documents the visual/atmospheric surface used by the next implementation stage, including `Stars`, `ScreenEffect`, `FogDistance`, `FogOptions`, `Particle`, `ScreenEffectColors`, `SunlightDampingMultipliers`, `SunlightColors`, `SunColors`, `MoonColors`, `SunGlowColors`, `MoonGlowColors`, `SunScales`, `MoonScales`, `SkyTopColors`, `SkyBottomColors`, `SkySunsetColors`, `FogColors`, `FogHeightFalloffs`, `FogDensities`, `WaterTints`, `ColorFilters`, `Moons` and `Clouds`.

## Particle System

Official asset path:

    Server/Particles/*.particlesystem

The 0.6.8 reference documents inheritance through `Parent`, spawner groups and culling/bounds controls such as `CullDistance` and `BoundingRadius`.

## Fluids / FluidFX

Official paths:

    Server/Item/Block/Fluids/*.json
    Server/Item/Block/FluidFX/*.json

These types expose native inheritance and particle/effect hooks; concrete overrides will be produced only after real IDs are audited.
